# Plan 3: Mac notch app

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The PlatyNotch.app users install: a notch panel showing agent sessions, approvals, now playing, next meeting, focus timer, open loops and memory search; settings and onboarding; on-screen text capture; signed, notarized, auto-updating releases.

**Architecture:** One Swift package (`apps/mac`). `PlatyNotchKit` holds models and all logic that can be unit-tested without a window (socket client, state store, geometry, state machines, parsers). `PlatyNotchUI` holds AppKit/SwiftUI and macOS integrations plus the plugin API Pro builds on. `PlatyNotch` is a three-line executable that calls `NotchApp.run`. The app launches the bundled `notch serve` and talks to it over the Plan 1 socket.

**Tech Stack:** Swift 6, SwiftUI + AppKit, Observation, Network.framework, EventKit, ApplicationServices (AX), Sparkle 2 via SwiftPM, `ungive/mediaremote-adapter` (BSD-3) for now playing.

**Spec:** `docs/specs/2026-10-23-platynotch-design.md`
**Depends on:** Plan 1 (protocol, `notch serve`, hooks CLI); Plan 2 for the Memory tab and capture.

## Global Constraints

- macOS 15.0 minimum, arm64 first (x86_64 builds allowed but untested).
- Bundle id `dev.platynotch.app` (placeholder); `LSUIElement` true; app name "PlatyNotch".
- The app never edits agent configs itself: it runs `notch hooks install|uninstall <agent>` and `notch statusline install|uninstall`.
- On launch: ensure `~/Library/Application Support/PlatyNotch/bin/notch` is a symlink to `Contents/MacOS/notch` of the running bundle.
- Approval card shows agent, project, tool and the exact `summary` in a monospaced, selectable, scrollable view; Allow is never the default for Return when the panel was not opened by the user (Return = nothing; ⌘↩ = Allow, ⌘⌫ = Deny).
- Capture runs only when `memory.enabled`, skips excluded bundle ids, skips while `IsSecureEventInputEnabled()`, and shows a capture dot in the menu bar icon while active.
- No network calls of its own except Sparkle's appcast check.
- Plugins (Pro) get only the public `PluginContext`; nothing in `PlatyNotchUI` may reference Pro.

## Review Focus

- Mac without a notch, external display main, or a full-screen app → pill under the menu bar, hidden over full screen, appears on hover at top edge (Task 3).
- `notch serve` crashes or is killed → app reconnects within 2 s and restarts it with backoff, UI shows "Reconnecting" not stale data (Task 2).
- Approval arrives while the panel is hidden or the Mac is in Minimal mode → panel peeks with the approval and stays until answered or expired (Task 4).
- Accessibility permission denied → capture is off with an explanation in Settings; the rest of the app works (Task 9).
- Two approvals at once from different sessions → both visible, ordered oldest first, each answered independently (Task 6).

### Task 4: App store and panel state machine

**Files:**
- Create: `Sources/PlatyNotchKit/AppStore.swift`, `Sources/PlatyNotchKit/PanelState.swift`; Tests: `AppStoreTests.swift`, `PanelStateTests.swift`

**Interfaces:**
- Produces:
  ```swift
  @MainActor @Observable public final class AppStore {
      public private(set) var sessions: [Session]; approvals: [Approval]; usage: Usage; loops: [Loop]
      public private(set) var memory: MemoryStatus; edition: String; connection: ConnectionState // .connecting, .connected, .reconnecting

  public struct SettingsSection: Identifiable { public let id, title, systemImage: String; public let view: AnyView }
  public struct PanelTab: Identifiable { public let id, title, systemImage: String; public let view: AnyView }
  @MainActor public protocol NotchPlugin: AnyObject {
      var id: String { get }
      func start(context: PluginContext)
      func settingsSections() -> [SettingsSection]
      func panelTabs() -> [PanelTab]
      func handle(event: ExtMessage)
      func handle(url: URL) -> Bool   // platynotch:// URLs not handled by the core app

      public let store: AppStore; public let client: CoreClient
      public let config: ConfigFileStore     // read/write config.json; writes trigger config.reload
      public func runCore(_ args: [String]) async -> (status: Int32, output: String) // runs the bundled core binary
  }
  public enum NotchApp { @MainActor public static func run(coreBinary: String = "notch", plugins: [NotchPlugin] = []) -> Never }
  ```
