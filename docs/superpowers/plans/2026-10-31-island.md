# Island (v0.4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Quiet Notch's austere Home with Island: a Now Playing card with an art glow, a Today card painted as the sky, a dock of eight round tools with badges and live states, in-place tool views, presets that visibly change Home, the dock, the pill and Agents, and a design lint that allows colour from content.

**Architecture:** Pure decisions stay in `PlatyNotchKit` with unit tests (tokens, the sky table, weather lines, location choice, last played, Today's bottom part, dock layout and state, timer presets, preset layouts, pill lead, usage rings, migration). `PlatyNotchUI` draws them behind seams (static `texts(...)`/`ids(...)` helpers, closure structs, injected services) that tests drive without live windows. Motion is Core Animation layers attached only while `\.panelTicking` is true. Three phases, each merged to main on its own and ending with the full suite, the smoke runs and perf-idle.

**Tech Stack:** Swift 6 / SwiftPM (`apps/mac`, macOS 15+), SwiftUI, AppKit, Core Animation, CoreLocation, XCTest; Go 1.27 core (`core/`, unchanged, built for the smoke runs).

**Spec:** `docs/specs/2026-10-31-island-design.md` (from the approved `docs/specs/2026-10-31-island-wireframes.html`). Every **[call]** in the spec is binding.

## Global Constraints

- Never use `isolated deinit`; CI greps for it.
- Wrap AVFoundation and QuickLook completion APIs in `withCheckedContinuation`, never their generated async forms.
- Pass the type-check guard `-warn-long-expression-type-checking=300`.
- Idle CPU stays under 1% (`scripts/perf-idle.sh`); animation uses Core Animation only, and only while the panel is open.
- New test classes that touch defaults use `DefaultsTestCase`.
- Every test or render window goes off-screen at (-10000, 10000).
- Never bundle third-party logos. App icons come from installed apps at runtime only. With no app, show the name as text, never initials.
- No emoji in the UI.
- Layout tests must not hard-code heights that differ between macOS 15 and 26.
- Showcase renders are forced to 2x.
- All builds use `--scratch-path /private/tmp/claude-501/pn-build-shared`, deleted at the end of each phase.
- `ApprovalSafetyTests` and `ApprovalArmingControllerTests` stay unmodified and pass.
- Approval keys never fire while a text field has focus.

## Review Focus

- Location access denied, or revoked after "Use my location" → the sky falls back to the saved city, else the "Add a city" state, and opening the panel never shows a Location prompt (Task 3 `testDeniedFallsBackWithoutPrompt`).
- Album art that is all black, all white or missing → the glow uses `DominantColor.fallback`, never black-on-black (Task 4 `testGlowFallsBackForMonochromeArt`).
- A dock slot whose widget is off, or a plugin tool whose plugin was removed → the first is dimmed and opens "Turn on", the second drops out, and the saved order is kept for when it returns (Task 7 `testMissingPluginDropsOutKeepsOrder`, Task 8 `testOffSlotOpensTurnOn`).
- A timer ends while the panel is closed → on open the Timer slot is no longer live and shows "Timer", with no tick while closed (Task 7 `testEndedTimerIsNotLive`, Task 9 `testDockLiveClearsWhenTimerEnds`).
- An approval arrives while the Note pad or search field has focus with text → ↩ appends or runs, ⌘↩ and ⌘⌫ edit text and never answer the approval (Task 10 `testNotePadNeverAnswersApprovals`).
