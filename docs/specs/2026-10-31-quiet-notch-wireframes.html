PlatyNotch v0.3 · design proposal · 31 Oct 2026 · 4 min read

Quiet Notch: fewer surfaces, only what's live

The redesign put every feature on screen at once. This proposal cuts the panel to two views, moves the long tail into Settings and a command line, returns to the dense v0.2 visual style, and fixes Open terminal. Nothing gets built until you say go ahead.

What's wrong today

  • Library is a drawer of everything. Twelve identical tiles: Weather next to Games, Platy Chase separate from Games, Focus next to Music. No product in the survey does this.
  • It looks generated. Big bordered hero cards, 28 pt titles, teal everywhere, tinted squares behind every icon, a "Cl" monogram that reads as "CI".
  • Hidden features. Keep Awake lives inside the Battery tile, so nobody finds it.
  • Open terminal is wrong. Your sessions run in the Claude app and agent-orchestrator, not Terminal or iTerm2, so the app guessed and opened whichever terminal was last used.
  • v0.2 looked better because it was dense, black and small-typed, with real agent glyphs and keycaps.

What the best notch apps do

A survey of NotchNook, Alcove, boring.notch, Atoll, DynamicNotch, DynamicLake, NotchDrop and the agent apps (Vibe Island, Notchly) found the same pattern:

  • Three to five things in the panel at most. The rest are switches in Settings.
  • Things appear when they matter: the file tray on drag, battery when you plug in, a timer while it runs.
  • One job per surface. Nobody ships an app grid.
  • Agent apps use a status-first row list with one click to the exact terminal, and approvals in place with keyboard shortcuts.

The new structure

Two views, Home and Agents. Agents only shows when agent hooks are set up. No Library. One header row carries the always-available toggles, and a command line (⌘K or just start typing) handles everything that used to be a tile.

Visual rules

  • Panel: always black, so it reads as part of the notch, like the Dynamic Island. No light-mode panel. Settings still follows the system.
  • Type: SF Pro 13 body, 12 secondary, 11 captions, one 13 semibold title per block. Nothing above 15 pt. SF Mono 12 for commands and numbers.
  • Colour: white at three opacities (92/56/32%). Colour only for state: green running, amber needs you, red error. Teal is gone.
  • Icons: SF Symbols, monochrome, 14–16 pt, no tinted squares behind them. Agents show their real icon from the installed app; with no app installed we show the name in text, never initials.
  • Shape: no bordered cards inside the panel. The only filled surfaces are the approval card, chips and the command line. Radii 6 / 8 / 12, panel bottom 22.
  • Motion: one spring for open and close. No bouncing text, ripples or celebrations.

Open terminal, fixed

Cause: the hook only records TERM_PROGRAM and the tty. Sessions inside the Claude app or agent-orchestrator have neither, so the app fell back to "most recent terminal".

Fix: the hook also records __CFBundleIdentifier, which macOS sets for every process an app launches. I checked: your Claude sessions report com.anthropic.claudefordesktop.

  • The button names that app: "Open Claude", "Open Ghostty", "Open Cursor".
  • It jumps to the exact tab where the app allows it (Terminal, iTerm2, tmux), otherwise brings that app forward.
  • It never guesses. If the app is unknown, the button becomes "Show folder".

Decisions for you

These are my calls. Change any of them.

1 Panel always black, no light mode.
2 Remove the pond scene and celebration moments. Platy stays: in the closed pill, the panel header and empty states.
3 Games leave the panel for the menu bar menu.
4 Home's right column is "Up next" by default; Notes or Mail can replace it in Settings.

Build order

  • 1. Open terminal fix and the header (Keep awake, Mirror, battery). Small, ships first.
  • 2. Structure: remove Library, build Home and the command line, move every feature per the table.
  • 3. Visual pass: black panel, type scale, icons, Agents rows, v0.2 approval card.

Each step merges to main separately, so you can test as it lands. Settings and data carry over; nothing you turned on is lost.
